更新：2026-10-25。当前为安卓个人本地版，正式工程已建立，五入口业务页面的实现边界见 [工程说明](../daily-life-android/README.md)。后续进度与验证证据统一在 [任务与交接](ai/开发任务与交接.md) 维护。

## AI 开发从这里开始

1. 阅读根目录 [AGENTS.md](../AGENTS.md)，了解项目规则。
2. 查看 [开发任务与交接](ai/开发任务与交接.md)，找到已授权任务和依赖。
3. 按下表读取相关章节，依据 [AI 开发执行说明](ai/AI开发执行说明.md) 实现、验证和交接。

用户最新明确要求优先。下表按领域确定依据，不按文件名中的数字比较：功能 V2 和 UI V3 管的是不同内容。

## 文档维护规则

- 功能或字段调整更新 V2；视觉调整更新 V3 和对应 JSON；实现方式调整更新技术/工程文档。
- 任务状态、实际命令结果和下一步只写入交接文件；本机日志可放忽略目录 `diagnostics/`，需要长期交接的结论不能只藏在本机日志里。
- 新增重复用途文档前优先更新现有文档；失效设计移入 archive 并加历史说明。
- 移动文件时同步相对链接；运行 `tools/Test-ProjectDocs.ps1` 检查本地链接、JSON 和设计变量的一致性。该检查不验证网页、安卓构建或真机行为。

AGENTS.md 的自动发现方式以 [OpenAI 官方说明](https://learn.chatgpt.com/docs/agent-configuration/agents-md) 为准；其他 AI 工具不一定自动读取，应明确让它打开项目指引。`docs/ai/` 的任务与交接文件是本项目约定，采用了 [官方工作流示例](https://developers.openai.com/cookbook/examples/codex/iterating-development-workflows-with-codex) 中将长期规则与执行记录分开的思路。
