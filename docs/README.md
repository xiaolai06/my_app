## 维护规则

- 功能或字段变更更新 V2；视觉变更更新 V3、设计系统与相关变量；实现方式变更更新技术/工程文档。
- 状态、实际验证和下一步只维护在交接文件，避免 README 重复积累版本日志。
- 被替代的旧方案与本机环境材料不继续入库；必要结论合并到现有有效文档，本机证据放在忽略目录 `diagnostics/`。
- 移动或删除文档同步引用。运行 `tools/Test-ProjectDocs.ps1` 检查本地链接、Markdown 和设计 JSON；该检查不验证安卓构建或手机行为。
