# “日常”UI 设计说明

> 历史三入口方案。当前采用用户确认的五入口完整个人版，视觉、导航、组件与动效以 [UI 与 UX 设计 V3](../iOS风格安卓UI与UX动效设计_V3.md) 为准；本文保留早期设计记录。

版本：设计规格 v1.2 · 2026-10-24

用户已确认用途为“个人日常待办＋随手记录”，并选中紧凑清单。名称暂用“日常”，保留绿色语义主色，全部组件统一采用视频参考的液态玻璃材质、柔和彩光和细高光边缘。底部采用固定等宽、上图标下文字的常规导航。材质与安卓实现以 [液态玻璃效果实现说明](../research/安卓液态玻璃效果实现说明.md) 为准；正式业务范围以 [开发说明](个人安卓App开发说明.md) 为准。

## 1. 设计方向

每天打开几次、单手快速操作、文字容易读，是这套界面的主要目标。以原生 Material 3 组件为基础，采用偏绿的主色、柔和浅底色和清楚的文字层级；主操作位置固定。

当前采用“紧凑清单”：首页用单列、较少留白和小间距玻璃任务行容纳事项，同时保留日期分组语义；记录按文字列表展示。此前的“舒适分组”保留作历史候选。任务、记录、按钮、复选框、搜索框、输入框、设置项、开关、弹层和提示采用同一套半透明着色、顶部亮边、底部细边和轻投影；正文与输入区提高着色遮盖度，文字和光标保持锐利。

本次对话中的交互预览用于观察页面和操作关系，采用示例数据与临时内存状态。它不包含 Room 持久化、系统文件选择器、实际草稿恢复或真正的数据备份；它与安卓安装包是不同交付阶段。

## 2. 信息结构

| 位置 | 名称 | 用户想完成什么 |
| --- | --- | --- |
| 底部入口一 | 今日 | 看待办、添加待办、完成事项 |
| 底部入口二 | 记录 | 写下和查找生活信息 |
| 底部入口三 | 设置 | 管理外观、备份和回收站 |
| 二级页 | 待办编辑 | 填写标题、备注、计划日期 |
| 二级页 | 记录详情／编辑 | 阅读和修改正文 |
| 二级页 | 备份与恢复 | 导出、选择文件、预览导入 |
| 二级页 | 回收站 | 恢复条目或永久删除 |

不设置个人头像、登录页或“我的账号”。第一版无需登录，首次打开直接进入今日；空白页面用提示和按钮教会用户开始。

## 3. 今日页

从上到下的内容：

1. 系统状态栏安全区域。
2. 简洁应用名“日常”，日期；主标题“今天，慢慢来”。
3. “今天／全部／已完成”筛选：今天只看当前需要处理的事；全部可找未来事项；已完成可回看历史。
4. 内容区域按“已逾期／今天／未设日期”显示。逾期以文字标识，配合语义颜色。
5. 每条待办左侧复选框，中间标题和日期／备注摘要。文字区域点击编辑，复选框只完成或取消完成。
6. 列表下方或右下角固定的扩展操作按钮“添加待办”；正式手机界面随列表滚动仍易触达。
7. 底部导航“今日／记录／设置”固定三个等宽点击区域，图标在上、文字在下且始终显示。底板连到页面底部，顶部有玻璃高光边，图标底板在自身入口内显示选中状态；切换只做短暂颜色与高光淡变，不跨栏滑动、不改变入口宽度。内容留足导航与系统 Insets 空间，原生 App 不绘制第二条系统手势条。

简化线框：

```text
日常                       10月23日
今天，慢慢来
还有 3 件事，按自己的节奏来

[今天]   全部   已完成

今天
□ 买一些新鲜水果
  今天
□ 给绿植浇水
  今天 · 记得看看土壤

未设日期
□ 整理旅行清单
  有空再慢慢补全

                   [＋ 添加待办]
       今日      记录      设置
```

数量来源于当前筛选结果，不显示虚构的完成率或连续使用天数。完成后可以短暂显示“已完成 · 撤销”，然后移到完成列表；提交失败应回退视觉状态并说明失败。

今天没有事项但存在未来计划时：显示“今天没有待办，未来计划可以在‘全部’查看”。首次无任何数据时：显示“把想做的第一件小事记下来”，配“添加待办”。全部已完成时可显示“今天的事都完成了”，不与从未录入的空状态混用。

“全部”页在筛选下方显示待办搜索框，匹配标题和备注；无结果时显示“没有找到相关待办”，清空后恢复全部未完成。跨入口切换返回时保留筛选和滚动位置；用户主动新增未来事项后切到“全部”，保证能立即找到刚添加的内容。

## 4. 待办编辑页

- 顶部返回按钮和标题“新建待办／编辑待办”，右侧主要操作“保存”。
- 首个字段为“要做什么”，可见标签＋输入框，必填；超限或为空时提示在字段下方。
- “备注”可选，多行输入。
- “计划日期”可选：未设日期／今天／明天／选择日期。日期只是清单分组，不显示容易误解为通知的铃铛。
- 编辑已存在事项时，在次级菜单提供“移到回收站”，不与保存并列为同等视觉重量。
- 初次输入时标题可获得焦点；软键盘弹出后内容可滚动，保存按钮可触达。
- 保存中显示进度并阻止重复提交；保存失败显示“没有保存成功，请重试”，保留内容。
- 返回涉及未提交内容时按开发说明处理草稿，不能直接退出丢弃。

## 5. 记录页和编辑页

列表页标题“随手记”，下面是带可见名称的搜索框，提示“搜索标题或正文”。按“置顶”“最近修改”分组；每条显示标题、两行正文摘要、更新时间。内容以文字为主，列表不采用高度不一的瀑布流，便于快速扫描。

底部主操作“写一条”。点击条目进入详情，正文完整展开；编辑入口明确可见。长正文自然换行、允许选择复制，不把用户文字塞进固定高度卡片。

编辑页提供标题、正文和保存。标题可空，但标题与正文不能同时为空；置顶是已有记录详情中的次级动作。空列表提示“先记下一件值得留住的小事”；搜索无结果提示“没有找到相关记录”，并提供清空搜索。

## 6. 设置、备份和回收站

设置以分组列表展示，不设计成数据看板。

| 分组 | 项目 | 显示内容 |
| --- | --- | --- |
| 外观 | 主题 | 跟随系统／浅色／深色 |
| 数据 | 备份与恢复 | 最近一次成功导出时间；从未导出显示“尚未备份” |
| 数据 | 回收站 | 删除内容仍可恢复；第一版不自动清空 |
| 关于 | 当前版本 | 例如 0.1.0，实际值从构建信息读取 |

备份页：顶部解释“把待办和记录保存成文件，换手机时可以导入”；主按钮“导出备份”，次按钮“从文件导入”。明确备份包含回收站内容，不包含草稿；备份文件为未加密文字数据。系统文件选择器中取消属于正常返回。

导入预览独立显示将加入、跳过和回收站数量，底部为“取消／确认导入”。旁边写清“已有内容保留本机版本”。导入成功才更新列表；错误页要指出文件过大、格式损坏或版本不支持，不能只显示失败代码。

回收站列表按删除时间降序，标注原类型；单条可以恢复或永久删除。永久删除使用确认对话框，显示名称及“此操作无法撤销”。避免把“清空全部”放在初版最显眼位置。

## 7. 配色规范

颜色按语义集中定义到 `ui/theme`，组件读取主题角色。下表是本方案自定义设计值，不是 Material 官方默认色，也不是自动生成的动态取色。

| 角色 | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| background | `#F6F7F3` | `#131B16` | 页面底色 |
| surface | `#FFFFFF` | `#1D2820` | 内容表面、弹窗 |
| surfaceVariant | `#EDF1EA` | `#29362C` | 输入背景、分组辅助底色 |
| onSurface | `#202B24` | `#E5ECE3` | 主要文字 |
| onSurfaceVariant | `#57645B` | `#B5C1B6` | 日期、备注、辅助文字 |
| primary | `#256A56` | `#9ED2B5` | 主按钮、选中项 |
| onPrimary | `#FFFFFF` | `#103926` | 主按钮上的文字 |
| primaryContainer | `#DDEEE5` | `#294D39` | 选中导航背景 |
| onPrimaryContainer | `#143E30` | `#C4EAD2` | 选中容器内文字 |
| outline | `#77857B` | `#829186` | 需要明确识别的控件边界 |
| divider | `#DCE3DA` | `#394A3D` | 装饰性分隔，不单独表达状态 |
| error | `#A72D35` | `#FFB3B8` | 错误和删除动作 |
| errorContainer | `#FFE8E9` | `#54262B` | 错误提示底色 |
| warning | `#94540D` | `#F4C785` | 逾期提示文字 |
| warningContainer | `#FFF0D8` | `#442E14` | 逾期提示底色 |

普通文字与实际背景目标对比度至少 4.5:1；表达控制和状态的图标／边界至少 3:1。检查实际组合，不把半透明后的结果当成原色计算。禁用控件另按平台约定处理。第一版先固定品牌色，动态壁纸取色留到后续，以减少需要验证的组合。

## 8. 字体、间距和组件尺寸

原生界面使用系统中文无衬线字体，不下载外部字体。尺寸以 Android 的 **dp／sp** 为准，原型中的网页像素只是视觉近似。

| 文字角色 | 大小／行高 | 字重 | 场景 |
| --- | --- | --- | --- |
| 页面主标题 | 28sp／36sp | 500 | 今天、随手记 |
| 二级页标题 | 22sp／28sp | 500 | 新建待办、设置 |
| 条目标题／正文 | 16sp／24sp | 400，标题可 500 | 待办、记录、输入 |
| 日期／辅助说明 | 14sp／20sp | 400 | 更新时间、提示 |
| 按钮／导航 | 14sp／20sp | 500 | 保存、添加、底部导航 |

| 项目 | 规格 |
| --- | --- |
| 手机左右留白 | 20dp；极小宽度可降至 16dp |
| 间距序列 | 4／8／12／16／24／32dp |
| 分组间距 | 24dp，组内条目间距 8dp |
| 待办行 | 最小 72dp，内容与大字体允许增高 |
| 输入框 | 最小 56dp，多行按内容增高 |
| 主要按钮 | 最小高度 48dp |
| 独立图标按钮 | 视觉图标 24dp，触摸区域至少 48×48dp |
| 形状 | 内容面 16dp，输入框 12dp，主要按钮按 Material 3 组件 |
| 阴影 | 内容列表通常无阴影；弹层使用 Material elevation |

Material 组件提供许多默认可访问语义，但仍需检查自定义组合。[Compose 可访问性与 48dp 触摸目标](https://developer.android.com/develop/ui/compose/accessibility/api-defaults)。

正式安卓图标统一使用一套 Material 风格本地矢量资源；示意预览使用统一 Lucide 线性图标作为近似。导航保留文字标签；删除等操作不能只靠一个无名称的图标表达。

## 9. 状态和反馈

| 状态 | 界面行为 |
| --- | --- |
| 初次加载 | 本地读取很快时直接显示；超出约 300ms 再显示加载提示，避免一闪而过 |
| 空内容 | 说明没有什么，并提供相关添加动作 |
| 搜索无结果 | 保留关键词，允许清空，不引导去创建无关条目 |
| 正在保存 | 保存禁用＋进度，内容保留 |
| 保存成功 | 数据已提交后返回并提示；不要重复弹确认框 |
| 保存失败 | 留在原页，错误就近可见，提供重试 |
| 数据读取失败 | 明确“读取失败”，提供重试；不能冒充“暂无内容” |
| 删除 | 移入回收站，并提供恢复入口；永久删除另行确认 |
| 文件操作取消 | 正常回到原页面，不当作错误 |
| 文件操作失败 | 提示具体原因，不声称完成，不更新时间 |

动效以 Material 组件默认反馈为基线；勾选完成和页面切换保持简短，约 120～240ms，最终以实际设备感受调整。遵循系统动画设置，不通过动画阻止再次操作；不循环闪动，不做无用途的入场动画。

## 10. 安卓适配与实现映射

- 用 `Scaffold` 管理顶栏、内容和底栏，正确应用其 padding；用系统 Insets 处理状态栏、手势栏和软键盘，避免重复加 inset。[WindowInsets 说明](https://developer.android.com/develop/ui/compose/system/insets)。
- 输入页处理 IME inset，长表单可滚动；系统返回优先关闭软键盘和当前弹层。
- 小于 600dp 的窗口先用单列；更大窗口保持文字区最大约 600dp 并居中，后续再考虑双栏，不在平板上把单行无限拉长。
- 不锁死竖屏，旋转后保留编辑内容和筛选状态；所有文字允许增高，不把任务行写成固定高度。
- 主按钮和底栏不得遮住最后一条内容；`LazyColumn` 底部预留实际操作区与系统 inset。
- 标题／分组标题有语义，复选框可读出“买水果，未完成／已完成”；装饰图标不重复朗读；单独图标按钮提供中文名称。
- 编辑器与底部导航组件只接收状态和回调，不自行访问数据库；屏幕级 ViewModel 管理数据状态。

| 设计元素 | 原生实现建议 |
| --- | --- |
| 三主入口 | NavigationBar / NavigationBarItem |
| 今天／全部／已完成 | TabRow / Tab 或对应 Material 3 分段控件 |
| 待办清单 | LazyColumn + 稳定 key + Checkbox + 分离的编辑点击区 |
| 表单 | OutlinedTextField、DatePicker、Button |
| 添加操作 | ExtendedFloatingActionButton |
| 删除／返回确认 | AlertDialog |
| 保存反馈 | SnackbarHost，错误同时保留在页面状态中 |
| 二级页面 | 类型安全导航参数只传 ID，进入后从数据层读取 |

## 11. UI 验收清单

以下是正式 App 需要执行的检查，不代表当前原型已经通过安卓真机验收。

- 320dp、360dp、约 412dp 宽度；横屏和大屏窗口。
- 系统字体 100%、150%、200%；长中文标题和超长单词不会撑破布局。
- 浅色、深色独立验证文字对比度和控件状态。
- 手势导航、三键导航、软键盘弹出时无按钮或输入被遮挡。
- TalkBack 遍历顺序、按钮名称、选中状态、错误提示都可理解。
- 减少／关闭动画后可以正常完成所有操作。
- 空列表、正常列表、1,000 条数据、超长正文、无结果、保存失败、备份失败均有完整状态。
- 返回不会静默丢弃修改，完成复选框不会触发编辑，编辑文字区不会误勾选。
- 预览中的示例文字和数据不会自动进入正式安装后的个人数据库。

已交付开发规格、逐页 UI 说明和可点击示意。早期功能原型用于讨论草稿、回收站与示例备份流程；当前玻璃风格预览集中展示今日／记录／设置、勾选、筛选、记录搜索、添加／编辑、深浅主题和减少动态。当前预览使用临时示例数据，没有真实数据库或文件备份；不能把早期原型演示的全部流程理解为当前玻璃版本已完成的原生能力。
