## V3.9 未完成编辑与完整月历

| 场景 | 当前规则 |
| --- | --- |
| 主编辑页退出 | 记录、计划、记一笔/报销及生活事项返回或“稍后继续”都先将最后输入写入现有草稿，成功后退出；失败保留输入，提交中禁止退出，不重复确认放弃 |
| 唯一身份 | 新内容有自己的稳定ID；同一原记录再编辑优先复用最新草稿，反复恢复/退出更新同一份。恢复重新读取本地草稿，保留原版本冲突检查；不按类型合并不同的新建内容，也不静默删除旧重复输入 |
| 我的 | 未完成编辑置于个人中心上方，预览最近3条，显示类型、事项、输入摘要、金额/日期和编辑时间；查看全部按四领域分组。点击回到对应编辑页，实际恢复成功才关闭列表，失败显示原因；损坏内容保留，可显式放弃 |
| 正式数据 | 只有正式保存参与列表、统计、账户分录、提醒和业务关系；草稿不计入。正式保存成功后当前草稿移除；显式放弃仍检查附件引用，不损坏正式记录或其他共享原件 |
| 数据工具 | “我的 → 数据与备份”集中领域ZIP备份恢复，以及账单CSV导入、账目CSV导出、记录Markdown和附件原件导出。账本浏览/统计不放导出按钮。文件选定后重新读取最新正式内容，导出不提交草稿、不改变余额；Markdown继续排除私密字段 |
| 日期面板 | 默认完整月格；普通360dp正文留12dp，保持七列48dp触区。年月居中、前后月按钮对称，选中为圆形填充，今天为描边，业务日期用圆点。月格/日期列表/手输可主动切换，确认前暂选，取消不提交 |
| 大字体 | 实际窗口决定布局；年月合为单行，模式条吸顶，日历正文纵向滚动，七列不足时横向浏览，固定底部操作。日期触区普通至少48dp、大字至少64dp；不通过缩小文字或触区塞下整月 |
| 动效与数据 | 沿用公共玻璃材质、220ms页面过渡与减少动态设置；无新增依赖、数据库迁移或备份格式。自动保留沿用已有Room草稿和附件隔离机制，更新失败不冒充保存成功 |

| --- | --- |

| 时间浏览 | 概况与统计提供日/月切换和前后时段；共享日期弹层可查看当天或当前浏览整月。切换时保留搜索、类型、分类及账户等条件，清除旧的自选日期范围；跨页保留所选时段 |
| 明细 | 日期与搜索同一行，其下为类型、分类、更多筛选下拉。账户、金额区间、自选首尾日期与预算条件集中在筛选面板，确认生效、关闭不改变原条件；激活的额外条件在列表顶部说明，可清除。父分类含其子分类，搜索识别父/子路径 |
| 概况与统计 | 概况突出支出、普通收入、结余、消费去向和最近账目；退款/报销有数据时单列。统计方向通过下拉切换；月视图包含当月每一天，日视图提供最近七天趋势，点日或分类进入对应明细。零值不画消费柱，不把转账、退款或报销算作普通收入 |
| 日期组件 | 月历、日期列表、手工输入可主动切换；大字体或窄屏默认日期列表，也可选择月历并横滑完整一周。日期至少48dp触区，主要操作固定，浏览月份不提前提交；“查看整月”使用当前浏览月份，手输模式使用有效输入月份 |
| 记一笔 | 56dp圆形玻璃新增按钮。金额、类型、日期、分类和支付方式优先；普通收支账户选填并置于更多信息，转账明确显示转出/转入。分类格等高、图标和文字居中；支付方式可设为常用，也可不选或清除常用 |
| 默认与退出 | 常用支付方式仅用于新建普通收支及保存后继续，不覆盖历史、复制、模板或恢复内容。返回直接放弃当前编辑，写入中禁止退出；不删除正式记录、共享附件或其他旧暂存，保存失败保留输入 |
| 次级功能 | 账户底部进入账本设置；预算、报销、导入、回收站及变更记录不占概况/统计头部。账本金额直接展示，不改变其他模块隐私偏好 |
| 导出范围 | 全 App 移除 Markdown、CSV 和附件原件的普通文件导出入口。个人中心按原领域保留 ZIP 备份与恢复；文件导入及文字分享保留 |
| 动效与适配 | 沿用220ms淡变和6dp轻移、选中填充渐变，减少动态时即时切换；旧页退场不可点。小屏日期工具区和大字体内容分行，分类、日趋势及选择项仍保持至少48dp触区 |

## V3.6 本地照片与生活工具展示

用户明确要求衣橱、穿搭和物品能展示自己的照片，保持本地存储；浏览方式可切换，外观设置应有直观预览。本节覆盖旧版仅网格衣橱、文件名为主的照片入口和纯文字外观设置；公共日期、选择、输入及保存规则沿用 V3.5。

| 页面 | 展示与操作 |
| --- | --- |
| 衣橱与穿搭 | 默认照片卡片，可切换紧凑列表；分类、搜索与收藏保留。收藏在卡片图片角落，名称与状态独立排列；列表使用缩略图、名称、类别/场景和穿着信息 |
| 物品、衣物、穿搭编辑 | 名称后直接出现照片区；支持系统照片选择、多张本地导入、查看原图、设封面和移除；原通用文件入口保留。其他工具的照片区收进“照片与附件” |
| 照片详情 | 以适应完整画面的方式显示图片，左右滑动浏览，显示页码与缩略图；点击进入现有原图查看器。无自有照片的穿搭可读取有效衣物的首张图片，不复制附件 |
| 清单 | 列表与卡片均显示已完成/总数，含条目时显示细进度条；详情保留真实勾选、分组与记账关系 |
| 纪念日 | 卡片突出天数或“今天”，随后显示名称与对应日期；详情突出倒数，保留原始日期与重复规则 |
| 订阅、缴费、借还、专题 | 列表/卡片显示对应的下一期、金额隐私、剩余数量或关联数；借还详情增加真实归还比例，原付款、调整和引用操作保留 |
| 外观与偏好 | 跟随系统/浅色/深色使用主题缩略预览；选中为 1dp 轻边与勾选。阅读与动效使用整行开关，称呼单独编辑并在成功后关闭；移除旧版硬编码版本和重复存储说明 |
| 数据与备份 | 按记录、计划、账本、生活工具四组展示导出/恢复，保留必要的原件备份提示与后续恢复确认 |

布局规则：衣橱照片卡片为两列，宽度小于 360dp 或字体大于 1.3 倍改一列；通用工具默认列表。每个模块单独记忆选择，不改变业务排序和数据。列表/卡片切换沿用同一惰性列表状态，位置变化 220ms；减少动态时不做位置动画。视图切换与收藏触区至少 48dp，照片编辑缩略图 68dp、详情缩略图 56dp；选中缩略图仅 1dp 边线。大字体分类纵向排列；主题预览在可用宽度小于 300dp 或字体大于 1.3 倍时变为横向预览列表。

本地与性能：照片经系统选择后复制到应用内部原件目录，不上传。沿用每张图片 20MB、每项最多 50 份附件限制。封面由第一个图片引用确定，在编辑暂存中调整，正式保存后生效；放弃不会改变正式顺序，共享附件仍检查全部引用。工具 ZIP 包含原件和顺序，显示方式属于本机 DataStore 偏好，不随工具 ZIP 导出。预览在后台解码，长边最多 720px、同时最多 2 个解码、内存缓存 16MB，并读取 EXIF 方向；不改写原图。列表不增加实时模糊或新图片依赖。

参考取舍：[Stylebook 官方功能](https://www.stylebookapp.com/features.html) 的衣物照片、搭配和穿着历史组织，以及 [Whering 官方说明](https://whering.co.uk/how-it-works) 的照片衣橱浏览。借鉴内容组织，保留本项目本地存储、蓝紫玻璃和原业务关系，未复制其素材或代码。系统选图与横向浏览分别依据 [Android Photo Picker](https://developer.android.com/training/data-storage/shared/photo-picker) 和 [Compose Pager](https://developer.android.com/develop/ui/compose/layouts/pager)。

实现：[ToolPhotos.kt](../../daily-life-android/app/src/main/java/com/example/dailylife/ui/ToolPhotos.kt)、[ToolCollections.kt](../../daily-life-android/app/src/main/java/com/example/dailylife/ui/ToolCollections.kt)、[AppearanceSettings.kt](../../daily-life-android/app/src/main/java/com/example/dailylife/ui/AppearanceSettings.kt)。检查证据与设备限制见 [照片与展示交接](../../docs/ai/开发任务与交接.md#lifestyle-photos)。

## V3.5 模块内页与公共组件

本轮用户授权优化各模块内部功能页面；保留 My Life 品牌、五入口与蓝紫玻璃主题。以下规则覆盖旧版各模块独立月历、长选项平铺与可滚动确认按钮的对应规定，不改变本地存储和业务字段。

| 场景 | 当前规则与实现 |
| --- | --- |
| 日期与时间 | 首页、记录、计划、账本和工具共用日期弹层，先临时选择再确认；月格从周一开始，支持年月跳转、今天、手工输入与有效日期校验。可用宽度不足 336dp 或字体倍率大于 1.3 时切换连续日期列表，确认栏保持可见；时间采用 24 小时输入及常用时刻，错误值不能确认 |
| 下拉与单选 | 标签在上、值在下的选择行，最小 64dp，16dp 圆角、0.75dp 细边。选项用惰性列表，最小 56dp；超过 8 项提供搜索及空结果反馈；已归档的原值仍可显示，不静默改写数据 |
| 多选 | 标签、进度来源、穿搭单品、导出字段统一先暂选后确认；关闭和返回不改变原集合。搜索时保留隐藏选择，勾选语义独立于单选；达到上限后仍可取消已选项 |
| 弹层 | 标题固定，正文按需滚动，主要确认操作固定在底部；日期列表单独滚动，手输日期正文可避让键盘。写入时禁止退出的弹层传入明确的关闭状态；失败保留输入 |
| 记录 | 筛选与批量归类采用紧凑资料夹/标签选择；日期范围显示校验结果；手账样式确认按钮固定；详情更多操作使用分隔列表，删除保持原有确认 |
| 计划 | 任务来源、关联任务、分组、目标进度来源和已有附件统一搜索/选择。主页面沿用下方计划细化规则；日期与提醒分开，不因选日期开启提醒 |

1. 顶部显示当前模块或页面，不显示应用宣传、版本口号和重复解释。外观页只保留可视化偏好；本机存储提示放在照片管理与备份等实际需要的位置，不硬编码版本装饰。
2. 左右边距 18–20dp；内容卡圆角 18dp，图标按钮圆形、文字按钮胶囊，输入和选择行 16dp（已有特殊字段 18–22dp），浮层 28dp，导航外框 32dp。
3. 浅色背景 `#F3F5FB`，正文 `#293442`，辅助文字 `#596579`，主色 `#505FAC`；蓝/淡紫/薄荷环境光静止。深色背景 `#151A28`、正文 `#F0F2FA`、主色 `#B9C4FF`。
4. 字号使用系统 sp。正文主要 16sp/26sp，列表辅助 15sp/23sp，小说明 13sp/20sp；导航 14sp/21sp 随系统放大；所有文字允许所需换行，不固定容器高度裁字。
5. 主按钮使用不透明蓝紫渐变保证白字可读；浮动新增按钮有实体底色，避免正文从下面透出。选择状态同时有底色、文字加重和语义。
6. 导航正文高 60dp、左右边距 16dp、真实底部 Insets；图标 20dp，触区至少 48×50dp。普通字号仅当前项显示 14sp 文字，选中圆角底板以 220ms FastOutSlowIn 平移，项目宽度同步变化；边缘 .75dp、轻阴影，无厚框和循环光效。大字体空间不足时等宽图标排列，下方完整显示当前名称，读屏始终提供全部名称和选中状态。
7. 根内容共享一个 Haze 背景源，只有导航采用 14dp 背景模糊，API31+ 启用。列表卡片与输入用静态玻璃材质，避免每一项采样。API26–30 和增强磨砂模式使用基础底色。
8. 这是参考组件的原生玻璃适配，包括背景模糊；没有实现物理折射、色散或 RuntimeShader 透镜，不把这些效果标为完成。
9. 主按钮按下缩放 0.98，紧凑新增按钮 0.96；按下 100ms、松开 160ms。根页与计划/账本/工具内容统一 220ms 淡变与 6dp 轻移，标题随对应根页一起过渡；账本普通字号底线 220ms 平移。淡出的旧内容不可点击或被读屏聚焦，切换关闭旧页输入法；不重建已保存的筛选、日期和滚动状态。减少动态同时服从系统和应用设置，取消缩放、平移和淡变；无背景循环动画。
10. 记录、计划、账本常用页与可新增的工具子页使用同一右下角玻璃「＋」：56×56dp、正圆、24dp图标、薄高光边缘与轻阴影。透明操作行左右18dp/上下8dp，正文独立测量，始终不遮挡末行金额或操作；大小不随字号膨胀。图标读屏名称和长按提示使用具体动作，写入忙碌时禁用；记录多选/回收站和纯计算工具不显示新增。保留既有真实玻璃导航增强，其余控件为静态透色材质，未实现物理折射。
10. 日期选择不自动开启提醒；取消不提交；保存结果仍来自 Repository。四模块主编辑退出自动保留未完成输入，在我的继续或明确放弃；同一内容更新同一份，正式保存后移除。金额隐私、防重复提交、删除和恢复保护不变。

- 顶部五子页合为单个玻璃导航面，固定宽度文字配滑动选中高光；不使用五个独立大按钮。正常宽度五项同时可见，大字体允许横向滚动且仅将选中项带入视野，不强制滚至最左。当前视图行使用 17sp 标题、向下箭头与数量，搜索/更多使用轻量 48dp 图标触区；不再重复大号蓝色标题。任务默认待办。新建按钮直接创建当前类型，跨类型创建位于任务更多菜单。高级筛选可一键清除。
- 子任务进度采用 8dp 圆角蓝紫渐变轨道，2–8 项按实际数量分段，更多项用连续比例；进度与数量放入同一行 48dp 展开触区。不绘制固定末端圆点。更新过渡 320ms，习惯与目标进度环 360ms、顶部高光 220ms；减少动态时立即到达终值。进度暴露真实比例和数量语义，零进度不画填充，无有效分母不造百分比。

- 任务为标题/完成框、简短日期分组摘要和按需子任务行；提醒以带语义的小图标表示，避免逐行重复“未设提醒”。习惯按进行中/暂停/结束分节，常态只显示名称、真实量值、进度和打卡；本周七格按需展开。目标按进行中/暂停/完成分节，标题、比例、5dp 进度和数量/截止摘要固定顺序；时长用小时/分钟/秒显示，存储仍为秒。读屏保持完整优先级、提醒和比例描述。
- 任务/日程/习惯的提醒独立于日期选择。重复任务只用相对提醒；已有独立提醒转为重复时明确提示其不适用于实例，不静默改写已有配置。目标沿用关联任务提醒，专注使用既有普通系统通知。
- 详情顶部只保留返回、短类型名和更多菜单，内容区使用惰性列表。任务/日程以原内容为主；习惯突出当天进度与打卡，目标突出真实比例与对应的记录进度/添加里程碑/关联事项动作。编辑、暂停、归档、重复系列管理等放入更多菜单，不在每条内容后常驻编辑。重复系列未选某次时显示实例列表，不对模板显示完成框。
- 习惯/目标历史行只显示日期、量值和短备注，点击后完整阅读备注，再按需修改或删除；归档/回收站内保留阅读，恢复后才能修改。里程碑保留直接完成操作，其余调整进入更多。关联来源打开原事项，返回回到原目标；来源多选暂存至确认，统一事务替换，失败保持选择与面板，不复制原业务对象。
- 专注运行页以标题、阶段、计时和一个主要操作构成。正计时显示已专注，倒计时/番茄阶段显示剩余；有效专注只累计工作分段，休息独立。暂停/继续、休息/下一轮随真实状态变化，结束进入二级面板；待核对必须先处理计时异常。存在活动专注时隐藏新增入口，结束后恢复。历史记录只读，备注和有效时长修正进入更多。普通计时 48sp，大字体采用 26sp 基准并随系统缩放，正文可滚动，触区不缩小。
- 新增/编辑复用公共字段、选择器与轻分组标题/分隔线，不再每组套一层玻璃卡片。名称、模式/目标、频率等常用项优先；低频日期/标记、休息、备注、重复、来源/标签、附件按需展开且保留输入。提醒保持简短状态行，可展开配置；正常状态不重复解释，真实错误和权限提示保留。底栏固定正式保存/开始及稍后继续，主编辑退出先实际暂存成功，失败留在原页，提交中禁止退出。
- 时长使用预设与小时/分钟/秒面板，确认才更新原值、取消不变；保留既有三位小数秒精度，不因展示换算取整。专注设置与历史修正遵循原整数秒及上限；目标进度可明确增加或扣减，历史修正允许零值。时长习惯的新打卡默认当日目标，修改旧记录保留原量值。选择面板的大字体内容可滚动，主要操作固定；数量键盘、字段启用和保存状态随真实状态更新。
- 多选模式的复选框只改变选择，子任务修改暂时禁用；筛选隐藏的条目从选择集合移除。批量完成、回收站/恢复和移动分组统一事务提交，失败保留选择与面板。归档/回收站内不能直接完成任务或修改子任务；需先恢复。无日期视图仅列未完成任务，选择冲突的状态筛选时切换至全部任务，避免无提示的空结果。
- 验证使用原生 Compose + Robolectric 截图与交互；真机通知到达、TalkBack、键盘和玻璃 GPU 效果仍须设备验收。最新结果见 [计划页交接](../../docs/ai/开发任务与交接.md)。

- 手账是可读内容容器：玻璃/奶油/横线/点阵，点缀色用于标题和细节。图文优先文字；拼贴优先照片；拍立得使用静止微倾斜纸框，不做循环摇动。大字体或可用宽度小于 260dp 使用单列；六张一组翻页，不同时解码全部附件。
- 预览后台最多两个解码任务，最长边约 720px、16MiB 内存缓存；载入与失败区分。原件仍由现有附件预览器打开。日记纸纹按尺寸缓存绘制，只有导航做背景模糊。
- 首页天气为可选卡片，禁用时显示设置入口；无天气时不画假温度。生活灵感显示具体原因，收藏点击打开原对象；所有新卡片可隐藏排序。

## 2026-10-26 首页内容优先改版

- 依据用户本轮要求，首页移除重复页头、顶部编辑、四个文字快捷新增和固定待办/完成统计块。保留日期入口，卡片设置统一在列表底部「卡片与样式」；提供柔彩/素净两种材质偏好，隐藏和排序只影响展示。

- 首页内容边距 20dp、卡片间距 16dp、卡片圆角 18dp。蓝紫为主色，习惯/账本用薄荷、生活/收藏用暖金、记录/灵感用淡紫图标点缀；无循环背景动画，深色和增强磨砂沿用公共主题。
